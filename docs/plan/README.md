# Plan Archive

## Purpose

存放 workflow 计划文档的归档索引。

## How To Enter This Section

- 执行前先维护 worktree 根 `plan.md`
- workflow 收敛后，再按需要将计划归入这里或迁移到全局控制面

## What Belongs Here

- 已完成 workflow 的计划归档
- 计划与需求/规范/变更之间的导航关系

## Naming / Maintenance Rules

- 叶子文档优先使用 `YYYY-MM-DD_topic.md`
- 计划必须显式记录 requirement/spec impact

## Current Docs

- 当前执行中的计划：[`../../plan.md`](../../plan.md)
- 历史遗留计划目录：[`../plan_archive/`](../plan_archive/)
